# 아직도 모르겠다. 기본 (원문 — 발행됨: posts/what-is-the-basics)

저 직원은 기본이 안되있어. 기본은 해야 할거 아냐...
20년이 넘었지만 기본이 뭘까? 누가 정해줬음 좋겠지만 기본은 아직도 어렵다.
엔지니어에게는 전자적인 지식이 기본이고 글쓰는 이들은 문법이 기본인가? 회사원들의 기본은 크게 사규가 기본인가? 너무 어렵다. 우선 기준이 다르다. 누구에게나 같은 기준으로 기본이라고 할 수 가 없다.
신입에게는 허용되는 기준이 시니어에게는 허용되지 않는 기본이 될 수 있다.
그래서 드는 생각은 기준은 태도인거 같다. 일을 대하는 태도. 회사의 사규를 다 알 수가 없다. 그렇게 교육받지도 않는다. 사규는 일반상식선에서 해결되지 않을 때 구역을 정해주는 헌법같은 거지 그거를 일일이 다 알수 가 없다. 물론 아는 사람도 있겠지만....
그래서 나는 기본이 없다는 말은 누구에게도 하면 안되는 말이라고 생각된다. 태도가 좀 안좋다 정도지 기본이 안됐다는 말은 너무 상처가 되는 말이다.
아직도 모르는 기본을 퇴직때가 되면 알까?
아직 기본을 모르나 보다.
