## 1. vMix 첫 세팅: 에디션 선택부터 Display 설정까지

**한 줄 소개:** 설치 후 30분 안에 "틀리면 나중에 전부 다시 해야 하는" 설정만 골라서 끝내는 강의.

**대상:** vMix를 처음 켜 본 사람, OBS에서 넘어온 사람 · 입문

**목차**
1. 에디션 비교: Basic HD / HD / 4K / Pro가 실제로 갈리는 지점(입력 수, 해상도, 리플레이, 두 번째 레코더, vMix Call 인원)
2. PC 사양에서 진짜 중요한 것: GPU(NVENC 세대), 코어 수보다 클럭, 캡처카드 PCIe 레인
3. Settings → Display: Output Size, Master Frame Rate를 카메라·송출과 맞추기(1080p 29.97 / 59.94)
4. Settings → Performance: 하드웨어 인코딩, 저지연 캡처, 멀티코어 설정
5. 오디오 기본값: Master 출력 장치, 샘플레이트 48kHz 통일
6. 프리셋 저장과 자동 로드

**실습:** 카메라 1대 + 마이크 1개로 Preview/Program 전환까지 완성하고 프리셋으로 저장

**자주 하는 실수:** 프레임레이트를 카메라와 다르게 두고 "왜 끊기지?" / Output Size를 4K로 두고 HD 캡처카드 사용 / 윈도우 사운드 장치 샘플레이트 불일치

## 2. 입력 소스 총정리: 카메라, 파일, NDI, 화면, 브라우저

**한 줄 소개:** vMix에 넣을 수 있는 모든 종류의 소스를 한 번에 훑고, 각 소스의 지연과 부하를 비교하는 강의.

**대상:** 입문~초급

**목차**
1. 캡처카드 입력(SDI/HDMI): 해상도·프레임레이트 자동 감지와 수동 지정, 오디오 임베디드
2. NDI 입력: 같은 네트워크의 카메라·PC·앱, Full NDI vs NDI HX의 차이
3. SRT·RTSP·RTMP 입력: 원격 카메라, IP 카메라, 타 PC의 스트림 받기
4. 파일 입력: 영상·오디오·이미지·리스트(List), 재생 코덱에 따른 CPU 부하
5. 화면 캡처: Desktop Capture vs NDI Screen Capture, 어느 쪽이 가벼운가
6. 웹브라우저·PowerPoint·Title·Colour·Blank 입력의 쓰임새
7. 입력 속성 창: 이름, 카테고리, 오디오, 위치/확대, 색 보정, 키잉

**실습:** 6가지 종류의 입력을 각각 하나씩 만들고 멀티뷰에서 동시에 띄우기

**자주 하는 실수:** 4K 파일을 그대로 넣고 렌더 드롭 / 브라우저 입력에 유튜브를 띄우고 오디오가 두 번 나옴 / NDI HX 카메라를 Full NDI처럼 지연 없이 기대

## 3. vMix 오디오 믹서 완전 정복: 게인, 버스, EQ, 컴프레서

**한 줄 소개:** 영상보다 먼저 사고 나는 오디오를 vMix 안에서 끝까지 책임지는 방법.

**대상:** 초급~중급 (음향 기초가 있으면 더 좋음)

**목차**
1. Audio Mixer 구조: 입력 채널 → 버스(Master, A~G) → 출력(스트림, 녹화, 헤드폰)
2. 게인 단계: 인터페이스 트림 → vMix Gain → 페이더, 어디서 키워야 하나
3. 채널별 처리: EQ(하이패스, 명료도 대역), 컴프레서, 노이즈 게이트, 딜레이
4. 버스 활용: 송출에는 넣고 현장 스피커에는 빼는 마이너스 원, 통역·리턴 버스
5. Auto Mix와 Audio Follow Video: 토크쇼에서 손 덜 가게 만들기
6. 레벨 기준: -18 dBFS 톤 라인업, 피크 -6 dBFS, 트루피크
7. 모니터링: 헤드폰 버스, Solo, 미터 읽는 법

**실습:** 마이크 2개 + 영상 파일 1개로 "현장에는 마이크만, 송출에는 전부" 버스 구성 만들기

**자주 하는 실수:** 마스터만 올리고 채널 게인은 바닥 / 노이즈 게이트 임계값을 너무 높여 말 끝 잘림 / 샘플레이트 불일치로 생기는 지직거림

관련 글: [트림과 페이더의 차이](https://warrendc50-gif.github.io/posts/audio-mixer-trim-vs-fader/), [목소리 EQ 정리](https://warrendc50-gif.github.io/posts/voice-eq-guide-hpf-q/), [dB 총정리](https://warrendc50-gif.github.io/posts/audio-db-guide-dbfs-true-peak-tone-lineup/)

## 4. 트랜지션과 스위칭: 컷부터 스팅어까지

**한 줄 소개:** "방송처럼 보이는" 전환을 만드는 트랜지션 설정과 스위칭 손버릇.

**대상:** 입문~초급

**목차**
1. Preview/Program 개념과 T-bar, Cut/Fade 버튼 4개 커스터마이즈
2. 기본 트랜지션: Fade, Zoom, Wipe, Slide, Fly, CubeZoom, Merge 등의 쓰임새와 시간(ms)
3. 스팅어 트랜지션: 알파 채널 영상 만들기(MOV/WebM), Stinger 1~4 설정, 컷 포인트 맞추기
4. FTB(Fade to Black)와 Quick Play
5. 트랜지션을 오디오와 함께: 오디오 페이드, 영상 끝나면 자동 전환(Trigger)
6. 멀티캠 스위칭 리듬: 발언자 따라가기, 리액션 샷, 너무 자주 바꾸지 않기

**실습:** 로고 스팅어 하나를 만들어 Cut 대신 모든 전환에 적용하고, 토크 3캠 스위칭 2분 연습

**자주 하는 실수:** 스팅어 영상 코덱이 알파를 지원하지 않음 / 전환 시간 1초 이상으로 늘어져 보임 / Program에 올린 뒤 Preview를 안 바꿔 다음 컷이 같은 화면

**대상:** 초급~중급

**실습:** 구글 시트에 발언자 이름을 적으면 로어서드가 바뀌는 구성 만들기

**자주 하는 실수:** 1080 캔버스에 720용 타이틀 / 폰트 미설치 PC에서 프리셋 열기 / 데이터 소스 셀 번호가 밀려 엉뚱한 이름 표시

## 6. 오버레이와 멀티뷰 레이아웃: PIP, 2분할, 4분할, 키잉

**한 줄 소개:** 화면을 쪼개고 겹치는 모든 방법을 한 강의에.

**대상:** 초급~중급

**목차**
1. Overlay 1~4: 각 채널의 트랜지션·위치·크기 기본값, 어떤 입력을 어느 채널에 둘지 규칙 정하기
2. 입력의 Multi View 탭: 레이어 10개, 위치·크기·크롭, 레이어 순서
3. 자주 쓰는 레이아웃 프리셋: PIP(강사+슬라이드), 2분할(대담), 4분할(멀티게스트), 세로 2분할
4. 크로마키·루마키: 키 색, 톨러런스, 스필 제거, 가장자리 처리
5. Zoom/Pan/Crop으로 카메라 1대를 2대처럼 쓰기
6. 레이아웃 전환을 쇼트컷·트리거로 자동화

**실습:** 강사 카메라 + PPT를 ① 풀 PPT ② PIP ③ 좌우 분할 세 레이아웃으로 만들고 버튼으로 전환

**자주 하는 실수:** 오버레이 채널 하나에 여러 입력을 번갈아 올리다 사라지는 자막 / 멀티뷰 입력의 원본 해상도가 낮아 흐릿함 / 크로마키 배경 주름·조명 불균일

## 7. 출력과 스트리밍 설정: Output 1~4, 외부 출력, 유튜브·페이스북 동시 송출

**한 줄 소개:** vMix의 출력 구조를 이해하고, 플랫폼별 권장 비트레이트로 끊김 없이 보내는 방법.

**대상:** 초급~중급

**목차**
1. Output 1~4와 Fullscreen, External Output: 각각 무엇을 내보낼 수 있나
2. 스트리밍 창: 3개 동시 송출, RTMP/RTMPS/SRT, 커스텀 서버
3. 인코딩 설정: 해상도, 프레임레이트, 비트레이트, 키프레임, 프로파일, 하드웨어 인코더
4. 유튜브·페이스북·트위치·네이버 권장값 비교
5. 회선 계산: 업로드 속도의 50~70%만 쓰기, 백업 회선(5G 테더링)
6. 끊김 원인 분리: 회선 vs 인코더 vs 렌더
7. 스트리밍 상태 읽기: 비트레이트 그래프, 드롭, 재연결

**실습:** 같은 영상을 유튜브(1080p 6 Mbps)와 테스트 서버(720p 3 Mbps)로 동시에 보내고 통계 비교

**자주 하는 실수:** 업로드 20 Mbps 회선에 12 Mbps 송출 / 1080i 소스를 그대로 송출 / 키프레임 간격을 플랫폼 요구(2초)와 다르게

## 8. 녹화 전략: MP4·vMix AVI·FFMPEG, 두 번째 레코더, MultiCorder

**한 줄 소개:** "녹화 화질이 떨어지거나 용량이 너무 큰" 문제를 포맷 선택과 역할 분리로 끝내는 강의.

**대상:** 초급~중급

**목차**
1. 포맷별 1시간 용량과 용도: MP4 25 Mbps(11 GB), vMix AVI(55 GB), ProRes(66 GB)
2. MP4 화질 저하 원인 6가지: 비트레이트, NVENC 프리셋, 프로파일, 인터레이스, 드롭 프레임, 출력 해상도
3. 편집 마스터는 vMix AVI → 필요할 때 Media Converter로 ProRes 변환
4. Second Recorder(4K 에디션 이상): 배포용 MP4 + 마스터 동시 녹화
5. MultiCorder: 카메라별 ISO 녹화, 디스크 쓰기 속도 계산
6. Fault Tolerant 포맷과 New File Every로 사고 대비
7. 녹화 로그 읽기와 복구

**실습:** MP4 8 Mbps / 25 Mbps / vMix AVI 세 가지로 같은 3분을 녹화해 용량·화질·CPU 비교

**자주 하는 실수:** 스트리밍 비트레이트 감각으로 녹화 비트레이트 설정 / 녹화 드라이브가 HDD나 FAT32 / 일반 MP4로 녹화하다 정전

관련 글: [vMix 녹화 화질·용량 정리](https://warrendc50-gif.github.io/posts/vmix-recording-quality-file-size-settings/)

## 9. NDI 실전: 네트워크 설계부터 NDI Bridge 원격 연결까지

**한 줄 소개:** 케이블 대신 네트워크로 영상을 나르는 NDI를 "되는 구성"으로 설계하는 강의.

**대상:** 중급

**목차**
1. NDI 종류: Full NDI, NDI HX2/HX3의 대역폭과 지연, 어떤 장비가 어느 쪽인지
2. 네트워크 설계: 1GbE에 Full NDI 몇 채널까지, 10GbE가 필요한 경우, 스위치 선택(멀티캐스트, IGMP)
3. vMix에서 NDI 보내기: Output을 NDI로, 오디오 포함, 알파 포함
4. NDI Screen Capture·NDI Tools: 발표자 PC 화면 가져오기
5. NDI Bridge: 다른 네트워크·원격지 연결, 포트 열기
6. 지연 측정과 동기: 카메라마다 다른 NDI 지연 맞추기
7. 장애 대응: Discovery Server, 방화벽, 같은 이름 충돌

**실습:** PC 2대로 vMix ↔ NDI Tools 왕복 연결, 1GbE에서 채널 수를 늘리며 드롭 시작점 찾기

**자주 하는 실수:** 와이파이로 NDI / 공유기 하나에 Full NDI 4채널 / 방화벽이 NDI 포트 차단

## 10. SRT 실전: 원격 중계, Caller·Listener, 지연과 암호화

**한 줄 소개:** 인터넷 너머의 카메라와 vMix를 안정적으로 잇는 SRT 설정과 장비 조합.

**대상:** 중급

**목차**
1. SRT가 RTMP와 다른 점: 패킷 복구, 지연 버퍼, 암호화
2. Caller / Listener / Rendezvous: 어느 쪽이 포트를 여는가, 공유기·방화벽 설정
3. Latency 값 정하기: RTT의 3~4배, 해외는 더 크게
4. Passphrase 암호화와 Stream ID
5. vMix 송신 ↔ 수신: vMix끼리, 하드웨어 인코더 ↔ vMix, 스마트폰 앱 ↔ vMix
6. 이기종 장비 호환 문제: 오디오 코덱, 설정이 다 맞는데 안 붙을 때
7. 여러 곳이 받을 때 대역폭: 1:1 구조라 접속 수만큼 업로드 필요

**실습:** 스마트폰 SRT 앱 → vMix 수신, 지연을 120ms / 500ms / 2000ms로 바꿔 가며 끊김 비교

**자주 하는 실수:** 양쪽 다 Caller / 지연을 너무 짧게 / 포트포워딩 없이 Listener

## 11. vMix Call: 원격 게스트를 방송 화질로 부르기

## 18. 프리셋 설계와 이중화: 매번 똑같이, 사고 나도 계속

**한 줄 소개:** 행사마다 처음부터 만들지 않는 프리셋 체계와, 메인 PC가 죽어도 방송이 이어지는 백업 구성.

## 20. 현장 운영 체크리스트: 리허설부터 종료 후 아카이브까지

**한 줄 소개:** 기술이 아니라 순서가 방송을 살린다. 실제 현장에서 쓰는 체크리스트 한 장.

**대상:** 전체 (운영자·행사 담당자)

**목차**

2. 현장 도착 후 60분: 설치 순서(전원 → 네트워크 → 영상 → 오디오 → 송출 테스트)

4. 리허설: 큐시트대로 1회 통과, 전환·자막·영상 재생 확인

**실습:** 체크리스트를 자기 현장에 맞게 수정하고, 모의 사고 2개(회선 끊김, 마이크 고장) 대응 연습

**자주 하는 실수:** 리허설 없이 본 방송 / 녹화 버튼 미확인 / 종료 후 파일 백업 전에 PC 종료

## 발행할 때 참고

- 블로그 글로 올릴 때는 각 항목이 글 한 편입니다. `broadcast` 카테고리로 두고, 질문은 Threads로 받는 한 줄을 끝에 넣으면 됩니다.
- 강의 커리큘럼으로 묶을 때는 1~8이 입문 과정, 9~15가 중급, 16~20이 운영 과정입니다.
- 쇼츠는 각 항목의 "자주 하는 실수" 하나씩을 30초로 만들면 20개가 나옵니다. `/shorts-plan` 스킬에 글 제목을 넣으면 기획안이 나옵니다.
